# 术语表

| 术语 | 定义 |
| --- | --- |
| **Irisa** | 平台名。承载 7 款反思游戏的底座 + 插件运行时。 |
| **网关 (Gateway)** | HTTP 入口：鉴权、限流、转发短请求；**持有 SSE 长连接**。一期与基座同 JVM。 |
| **底座 / 基座 (Base)** | 身份、账本、领域事件、Agent、Cron、Webhook、全局画像。不持有浏览器连接。 |
| **游戏 / 插件 (Game Service)** | 实现插件契约的 Modulith 模块。一个游戏 = 一套玩法 + 一套前端路由 + 一组事件订阅。 |
| **玩家 (Player)** | 登录用户。所有游戏共享同一个 `player_id`。 |
| **全局画像 (Persona)** | 底座维护的极客性格快照：代码信用分、心智健康度、偏见标签、社交能量净值。只读给游戏，只由事件写入。 |
| **代码信用分 (Code Credit)** | 0–1000 整数。闹鬼档案扣分，银行坏账扣分，按时还债加分。 |
| **心智健康度 (Mind Health)** | 0–100 整数。病理诊断主写；过低时其他游戏 NPC 态度恶化。 |
| **事件 (Event)** | 跨游戏唯一通信单元。不可变，落 MySQL `event_log`，热路径可进 Redis。旧称「信号」。 |
| **账本 (Ledger)** | MySQL 中不可改写的事实记录：庭审结案、病理报告、债务凭证、誓言原文。 |
| **记忆 (Memory)** | ES 中的文本与向量：誓言、聊天快照、收藏文章、幽灵案情、庭审笔录。 |
| **Agent 线程** | 底座拉起的一次有界 LLM 调用。有角色、工具白名单、回合上限、token 预算。 |
| **审计员约束** | 法庭审计员只能调用 `FactTool`，禁止自由发挥。输出必须带数据源引用。 |
| **幽灵 (Ghost)** | 闹鬼档案对一类技术债的具象。种类：怨灵 / 僵尸 / 灵异抓狂。 |
| **债务凭证 (Debt Note)** | 银行对一段脏代码的金融化记录：本金、利率、引用入度、坏账标记。 |
| **破产清算 (Bankruptcy)** | 利息突破交付能力阈值后的强制动作：Slack 红牌 + `[BANKRUPTCY]` PR。 |
| **回音 (Echo)** | 回音壁在玩家背叛誓言时弹出的全屏拷问。触发条件由 Cron + 病理事件共同判定。 |
| **杠精分身 (Devil's Advocate)** | 偏振器拉起的反方 Agent，只允许攻击当前命题，禁止人身攻击。 |
| **事实工具 (FactTool)** | 底座提供的只读工具：查账本、查画像、查银行头寸、查病理最近 N 份报告。 |
