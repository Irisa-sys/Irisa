# 平行宇宙档案馆 Spec

玩法以 `00-multiverse-archive.md` 为准。界面气质以 `03-ui-style.md` 为准。跨游戏运行、授权、检索、取消和防腐以 `04-backend-spec.md` 为准。

## Problem Statement

玩家需要一条可暂停、可继续、可回看的平行时间线：从过去没走的路分叉，或从现在开始探索另一条路。如果系统一次写出整段未来、把未确认法庭假设当成起点、或在资料不足时替平行的你做决定，这就不再是平行宇宙游戏，而会变成伪预测或人生建议。

玩家需要：创建时只使用已授权资料；普通事件自动推进；重大决策可介入或交给平行的你；资料不足必须停下；离线可按步数推进但遇决策或缺口即停；撤回授权不改写已经发生的宇宙经历。

## Solution

档案馆以宇宙为聚合。历史分叉只能从 indexing 中当前仍授权的决策资料创建；未来选择可独立创建。玩家确认设定后才分配宇宙编号并开始推演。档案馆领域只认决策资料、画像资料和本宇宙经历，不出现法庭或偏振器语义。

在线每次只生成并提交一个完整事件。离线按最大步数推进，但同一宇宙同时只能有一个推进任务。重大决策和资料缺口停下。宇宙既定经历优先于起点设定，再优先于已确认现实资料，再优先于后续新增资料。

创建时保存本次使用资料的快照。后续撤回授权只影响之后的检索和推演。分享只读脱敏快照，可撤销。取消当前在线生成不停离线任务。

## User Stories

1. As a 玩家, I want 在开始前看到这是虚构平行宇宙叙事, so that 我不会把它当成现实预测或人生建议。
2. As a 玩家, I want 从仍授权的决策资料创建历史分叉, so that 宇宙从当时真实选择时刻开始。
3. As a 玩家, I want 历史分叉只使用我确认且当时可行的未选路径或自定义替代行动, so that 角色猜测不会成为起点。
4. As a 玩家, I want 没有决策资料时也能从现在创建未来选择, so that 我仍能探索尚未走过的路。
5. As a 玩家, I want 创建未来选择时说明方向、目标和最初行动, so that 起点足够明确。
6. As a 玩家, I want 系统追问 2-3 个影响起点成立的关键问题, so that 关键事实不会被猜测替代。
7. As a 玩家, I want 非关键问题可以暂不确定, so that 我不必填完所有细节才能开始。
8. As a 玩家, I want 按内容范围选择本次宇宙可以使用的资料, so that 不想用的材料不会进入这个宇宙。
9. As a 玩家, I want 在设定确认页看到起点、已知事实、限制和资料来源后再开始, so that 编号不会在我反悔前被占用。
10. As a 玩家, I want 确认后才分配宇宙编号并进入第一次生成, so that 没有半成品宇宙。
11. As a 玩家, I want 书架上看到编号、名称和状态, so that 我能认出每一册宇宙。
12. As a 玩家, I want 打开宇宙后按宇宙内时间阅读事件, so that 时间线是这个宇宙自己的时间。
13. As a 玩家, I want 事件按时间、标题、正文、我的行动排列, so that 阅读顺序稳定。
14. As a 玩家, I want 每次在线继续只出现一个新事件, so that 我可以一步一步看。
15. As a 玩家, I want 普通事件自动完成并写入时间线, so that 不是每次都要做选择。
16. As a 玩家, I want 重大决策时选择我来介入或让平行的我决定, so that 控制权在我。
17. As a 玩家, I want 资料不足时不要出现让平行的我决定, so that 系统不会无依据替我行动。
18. As a 玩家, I want 介入后看到 3-4 个具体行动和自定义方向, so that 我能选一个可执行的行动。
19. As a 玩家, I want 行动选项没有推荐、没有结果预测、没有好坏排序, so that 我不是在被建议人生。
20. As a 玩家, I want 自定义方向明确且不与既定经历冲突时直接成为本次行动, so that 不必为清楚的输入再被追问。
21. As a 玩家, I want 自定义方向含糊或冲突时被追问, so that 含糊输入不会直接写进时间线。
22. As a 玩家, I want 让平行的我决定后立刻看到采取了什么行动, so that 我知道这一步已经落定。
23. As a 玩家, I want 不提前看到该行动的后果, so that 后果由后续事件自然出现。
24. As a 玩家, I want 可选查看为什么这样做, so that 解释只引用本宇宙经历、处境和已确认判断。
25. As a 玩家, I want 介入后可选填写我这样做是因为, so that 理由成为这个宇宙里“我”的一部分。
26. As a 玩家, I want 行动和理由一经确认不可修改, so that 既定经历保持稳定。
27. As a 玩家, I want 自定义方向的原始输入不出现在时间线, so that 对外只保留忠实的行动描述。
28. As a 玩家, I want 缺少关键资料时看到 2-4 个中性事实选项和自定义补充, so that 我能补上必要事实。
29. As a 玩家, I want 补充后看到更新过的当前事件再继续, so that 新事实立刻进入当前情境。
30. As a 玩家, I want 非关键缺失可以跳过, so that 推演能以当前抽象程度继续。
31. As a 玩家, I want 设置最大步数启动离线推演, so that 离开后仍能推进。
32. As a 玩家, I want 离线在达到步数、重大决策、缺少资料、异常、暂停或完结时停止, so that 它不会悄悄替我做重大决定。
33. As a 玩家, I want 离线不因退出页面自动开始, so that 推演仍是我主动发起的。
34. As a 玩家, I want 同一个宇宙不能同时跑两路推演, so that 时间线不会分叉错乱。
35. As a 玩家, I want 离线过程中仍能查看已写入事件, so that 我可以阅读，但不能再开新推演。
36. As a 玩家, I want 某一步生成失败时保留前面完整事件, so that 失败步骤不会留下半个事件。
37. As a 玩家, I want 异常暂停后选择在线一步或重新开离线, so that 恢复由我发起，系统不自动重试。
38. As a 玩家, I want 选择细致、正常或快速节奏, so that 之后事件的时间跨度和长度符合我的阅读偏好。
39. As a 玩家, I want 改节奏不回写已经发生的事件, so that 过去的粒度保持原样。
40. As a 玩家, I want 当前状态只包含已确认事实、计划和明确状态, so that 看不到心理揣测或未来预测。
41. As a 玩家, I want 补充当前情况后从当前节点生效, so that 过去的事件不被重写。
42. As a 玩家, I want 与既定经历冲突的补充被改写成从现在起成立的新变化, so that 我不能把“过去一直如此”塞进已经发生的时间线。
43. As a 玩家, I want 随时撤回某项资料授权, so that 后续推演不再使用它。
44. As a 玩家, I want 撤回后已经发生的事件保持原样, so that 平行经历不被改写。
45. As a 玩家, I want 查看本宇宙资料来源, so that 我知道它从什么材料起步。
46. As a 玩家, I want 暂停、完结或删除宇宙, so that 我能管理这些时间线。
47. As a 玩家, I want 完结前选择是否生成中性摘要, so that 完结后仍有一份可回看目录。
48. As a 玩家, I want 摘要失败也不阻止完结, so that 宇宙仍能变成只读。
49. As a 玩家, I want 已完结宇宙不能恢复推演, so that 只读就是只读。
50. As a 玩家, I want 删除前二次确认，删除后时间线、检索内容和任务都不可再访问, so that 我能拿走这个宇宙。
51. As a 玩家, I want 分享前预览脱敏结果, so that 姓名、公司、城市、收入、联系方式不会原样公开。
52. As a 玩家, I want 分享链接只读且可撤销, so that 持有链接的人不能继续推演或查看资料来源。
53. As a 玩家, I want 分享页固定说明这是虚构叙事, so that 外人不会把它当成现实经历。
54. As a 玩家, I want 取消当前这次在线生成, so that 半个事件不会写入时间线。
55. As a 玩家, I want 取消当前生成时离线任务不受影响, so that 取消对话不等于暂停宇宙。
56. As a 玩家, I want 打开长期暂停的宇宙时先看到停在哪个宇宙时间, so that 我能接着读，而不是先看回顾。
57. As a 平行的你, I want 自动决断时先服从本宇宙既定经历, so that 我不会因为新的现实资料突然换性格。
58. As a 实现者, I want 档案馆只通过 indexing 读取决策资料和画像资料, so that 未确认假设进不来，领域里也不出现来源游戏。
59. As a 实现者, I want 宇宙时间线事件不要写成跨模块领域事件, so that 一次推演步骤不会混进基座通知。
60. As a 实现者, I want 命令接口成为本游戏主测试缝, so that 推进一步、离线停止和授权撤回可以不连中间件验收。

## Implementation Decisions

### 命令

档案馆命令接口至少支持：

- 基于 indexing 中当前仍授权的决策资料创建历史分叉草稿。
- 创建未来选择草稿。
- 回答起点关键问题，标记非关键问题为暂不确定。
- 按内容范围选择本次使用资料并确认设定。
- 确认后正式创建宇宙、分配玩家范围内递增且不复用的编号、开始第一次生成。
- 在线继续一步。
- 在资料充足的重大决策中选择介入或交给平行的你。
- 选择具体行动或提交自定义方向。
- 补充关键或非关键资料。
- 补充当前情况。
- 启动、暂停、停止离线任务，并设置最大步数。
- 查看时间线、当前状态、资料来源。
- 完结宇宙，可选生成摘要。
- 删除宇宙。
- 预览脱敏、创建分享、撤销分享。
- 取消当前在线运行。
- 撤回某项资料在后续推演中的使用。

确认设定前不得分配编号，不得写入第一条时间线事件。

### 宇宙状态

可见状态至少包括：运行中、等待你的决定、等待补充信息、离线推演中、离线推演已达到步数、系统异常等待继续、已完结只读。

同一宇宙同一时刻只能有一个推进任务。离线进行中不得再启动在线或另一路离线。删除必须先停止任务。

历史分叉的时间起点是原选择时刻，不是今天审理或今天创建的时刻。未来选择的时间起点是创建时的当前时刻。

### 事件提交

一次成功推进一步，只提交一个完整时间线事件，并更新当前状态事实。事件至少包含稳定标识、宇宙内顺序、宇宙内时间或时间范围、标题、叙事、中性背景、可选的我的行动、行动来源的内部记录。

失败或取消时，当前未完成事件不提交。此前完整事件保留。

行动选项不得附带结果预测、风险比较或推荐。平行的你给出的解释不得引用未授权或未确认材料，也不得预告后果。

### 资料优先级

推演和自动决断按此顺序：宇宙既定经历，高于宇宙起点设定，高于已确认现实资料，高于后续新增现实资料。

未进入 indexing 的内容不得用于创建、检索或自动决断。新的已授权现实资料只影响当前节点之后。宇宙 RAG 只保存本宇宙经历，不回写 indexing。

宏观背景在宇宙开启时快照，之后不自动同步新的现实世界变化。

### 分享与删除

分享生成只读快照。快照不含资料来源、宇宙检索内容、未脱敏原文或继续推演入口。撤销后原链接不可访问。

删除后，玩家不能再读取该宇宙的时间线、当前状态、检索内容、摘要、任务和分享管理。编号不复用。

### 运行

在线事件生成、行动解释、资料整理、摘要生成创建运行并流式输出。取消当前运行只丢弃这次未提交生成。离线任务继续与否由任务命令决定，不由取消当前生成决定。

## Testing Decisions

主测试缝是档案馆命令接口。测试用内存适配器，不连中间件。indexing 在测试中以 materials/search 替身提供决策资料和画像资料。

必须覆盖：

- 不在 indexing 中或已撤回的决策资料不能创建历史分叉。
- 未确认路径不能作为替代行动。
- 确认设定前不分配编号、不出现宇宙。
- 在线一步最多新增一个完整事件。
- 资料不足时不能选择让平行的你决定。
- 行动选项不含预测或推荐。
- 同一宇宙拒绝第二个并发推进任务。
- 失败或取消不留下半个事件；前序完整事件仍在。
- 离线在重大决策或资料缺口处停止。
- 撤回授权后后续生成不得再检索该资料；已写入事件不变。
- 补充当前情况与既定经历冲突时，不得写成过去一直如此。
- 已完结宇宙拒绝继续推演。
- 撤销分享后不能再读到快照。
- 取消当前在线生成不停已经在跑的离线任务。

不断言封面生成、翻书动效、真实检索实现或消息中间件。

## Out of Scope

- 从既有宇宙历史节点 Fork。
- 编辑或删除已经发生的关键选择。
- 宇宙内纠正既定事件。
- 按主题设置介入偏好。
- 手动排序宇宙列表。
- 系统推送通知。
- 自动生成确定的 1 年、5 年、10 年人生结论。
- 把模型推测写入现实个人资料。

## Further Notes

MVP 时间线事件保留稳定标识、宇宙内顺序和所属宇宙，仅为以后 Fork 预留，本 spec 不实现 Fork。平行的你不是玩家本人，只是这条时间线里已经形成的那个“我”。推演时语义检索走 indexing；本宇宙既定经历走宇宙 RAG。
