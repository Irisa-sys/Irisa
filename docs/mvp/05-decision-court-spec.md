# 人生决策法庭 Spec

玩法以 `01-decision-court.md` 为准。跨游戏运行、授权、检索、取消和防腐以 `04-backend-spec.md` 为准。

## Problem Statement

玩家需要把一段真实人生选择审理清楚：当时发生了什么、有哪些路、为什么那样选。固定三轮、角色各说一次就结束，会把还没问清楚的阶段强行推走。未确认的角色假设如果流进档案馆，会把猜测写成可分叉的历史。

玩家需要：阶段可以继续、必须自己确认才进入下一阶段、回退后按最新内容重新全员审理、尚未做出的现实选择不能结案、只有自己确认过的内容才能授权给档案馆。

## Solution

法庭按三个主题阶段进行：事实、路径、判断。首次进入阶段时五个角色依次发言；之后可以由相关角色或玩家点名的角色继续。书记员只整理，不宣布阶段完成。玩家确认后才进入下一阶段。玩家可以回到上一阶段；回退后基于最新确认内容重新进行一轮全员庭审，再回到离开时的阶段。

尚未完成的现实选择只能保存为审理中或待补充，不能结案。结案档案只包含玩家确认过的内容。结案或授权变更后，本模块发布领域事件，payload 已是决策资料字段，供 indexing 异构。角色提出的新路径必须经玩家确认，才能成为案件材料和决策资料。

生成过程走统一运行与 SSE；取消只停当前这次生成。

## User Stories

1. As a 玩家, I want 提交一个具体选择作为案件, so that 我能审理一段真实经历而不是一种模糊情绪。
2. As a 玩家, I want 系统在信息不足时最多问三个关键补充问题, so that 我知道缺的是定位选择所必需的内容。
3. As a 玩家, I want 补充后仍无法定位选择时案件停在需要补充, so that 不合格案件不会进入庭审。
4. As a 玩家, I want 开庭前确认时间、实际路径、候选路径、事实和不确定内容, so that 角色不能擅自改我确认过的事实。
5. As a 玩家, I want 选择本次庭审可以使用哪些个人资料, so that 法庭不会读取我没有允许的内容。
6. As a 玩家, I want 开庭前逐项修正卷宗, so that 进入庭审时用的是我认可的起点。
7. As a 玩家, I want 三个阶段分别处理事实、路径和判断, so that 每次只盯一个主题。
8. As a 玩家, I want 首次进入阶段时五个角色依次发言, so that 我能听到完整的五种立场。
9. As a 玩家, I want 过去的你只站在当时说话, so that 后来才知道的结果不会冒充当时动机。
10. As a 玩家, I want 悲观主义者追问最坏代价但不把最坏说成必然, so that 尖锐不等于恐吓。
11. As a 玩家, I want 机会主义者提出可能被忽略的路但不把机会说成保证, so that 替代路径仍然要付出代价。
12. As a 玩家, I want 审计员在没有资料时明确说卷宗空白, so that 金额、健康、法律等内容不会被编造。
13. As a 玩家, I want 书记员区分事实、叙述、评价、假设和角色分析, so that 我看清什么已经被确认。
14. As a 玩家, I want 角色都发过言也不自动进入下一阶段, so that 阶段完成由我决定。
15. As a 玩家, I want 书记员总结后选择继续当前阶段, so that 没问清的问题可以接着问。
16. As a 玩家, I want 继续时由和未解问题最相关的角色追问, so that 不必每次五个角色全部重来。
17. As a 玩家, I want 点名一个角色继续追问, so that 我能指定想继续的立场。
18. As a 玩家, I want 继续追问时角色不得开启新的阶段主题, so that 事实阶段不会突然变成判断阶段。
19. As a 玩家, I want 补充、更正、澄清或指出角色误解, so that 庭审跟着我的经历走。
20. As a 玩家, I want 说明某条路径当时其实不可行, so that 事后想象不会变成当时选项。
21. As a 玩家, I want 把某项内容标记为我不确定, so that 空白不会被填成事实。
22. As a 玩家, I want 角色提出新路径后必须由我确认当时是否可行, so that 讨论中的假设不会自动进入案件档案。
23. As a 玩家, I want 不确认的新路径只留在讨论记录里, so that 结案时不会把它写成真实选项。
24. As a 玩家, I want 连续追问没有新内容时得到明确提示, so that 我知道是继续还是接受不确定性。
25. As a 玩家, I want 即使没有新内容也可以继续当前阶段, so that 系统不能替我结束。
26. As a 玩家, I want 接受当前整理后再进入下一阶段, so that 推进是我的确认。
27. As a 玩家, I want 进入后续阶段后仍能回到上一阶段, so that 后来发现的遗漏可以补上。
28. As a 玩家, I want 回退时以上一阶段最新确认内容为基础, so that 重审看到的是现在的事实而不是过时摘要。
29. As a 玩家, I want 回退后重新进行一轮全员庭审, so that 五个角色都对更新后的内容重新回应。
30. As a 玩家, I want 回退重审结束后由书记员重新总结, so that 我再次确认该阶段。
31. As a 玩家, I want 确认回退阶段后回到原先离开的阶段, so that 回退不是重开一局。
32. As a 玩家, I want 回退造成后续阶段过时时旧总结只作讨论记录, so that 最终结论以最新确认为准。
33. As a 玩家, I want 已经发生的庭审对话不被删除, so that 我能回看讨论痕迹。
34. As a 玩家, I want 更正后仍保留原先说法作为痕迹, so that 结案用最新确认，过程可追溯。
35. As a 玩家, I want 在阶段未完成时离开并稍后继续, so that 长审理不必一次做完。
36. As a 玩家, I want 回来后从当前阶段未解决问题继续, so that 进度不会丢失。
37. As a 玩家, I want 一局只围绕一个选择, so that 另一个选择必须另开案件。
38. As a 玩家, I want 三个阶段都完成后再确认选择时点、实际路径和未选路径, so that 结案前我重新看一遍。
39. As a 玩家, I want 尚未完成现实选择的案件不能结案, so that 没有实际路径的案件不会被当成历史分叉材料。
40. As a 玩家, I want 未决定的案件保存为审理中或待补充, so that 我以后能回来补实际路径。
41. As a 玩家, I want 只有已决定或无法验证时才能签名结案, so that 签名对应一次已经发生的选择。
42. As a 玩家, I want 无法验证表示选择已经发生但关键内容无法可靠还原, so that 它不会和尚未决定混在一起。
43. As a 玩家, I want 签名只表示确认这份记录, so that 它不等于同意某角色观点，也不等于某条路更好。
44. As a 玩家, I want 结案档案包含当时资源、限制、看重的东西、起作用的理由和后来结果, so that 我能回看完整决策档案。
45. As a 玩家, I want 结案档案写明我现在如何理解这次选择, so that 当前评价和当时选择被分开。
46. As a 玩家, I want 结案档案只说明仍存在不确定性, so that 未确认假设本身不会被写成档案内容。
47. As a 玩家, I want 按内容范围选择档案馆可以使用哪些材料, so that 我能只交出路径和处境、留下家庭细节。
48. As a 玩家, I want 随时撤回档案馆授权, so that 后续宇宙不再读取被撤回内容。
49. As a 玩家, I want 角色发言一段一段出现, so that 我能边看边等完整段落。
50. As a 玩家, I want 取消当前这次生成, so that 不想继续的半段发言不会落库。
51. As a 玩家, I want 取消后仍能继续当前阶段, so that 取消不是放弃案件。
52. As a 玩家, I want 刷新后只看到已提交的发言和总结, so that 流式草稿不会冒充庭审记录。
53. As a indexing, I want 只收到已结案且玩家确认的决策资料事件, so that 未确认假设不会成为历史分叉起点。
54. As a indexing, I want 未选择路径只有在玩家确认当时可行后才进入决策资料, so that 角色猜测不会变成宇宙起点。
55. As a 实现者, I want 法庭命令接口成为本游戏主测试缝, so that 阶段推进、回退和结案规则可以不连中间件验收。
56. As a 实现者, I want 本域事件不携带讨论中的假设, so that indexing 天然带资料边界。
57. As a 实现者, I want 模型生成的角色发言先按阶段主题和资料边界校验再提交, so that 角色不能把空白写成事实。
58. As a 玩家, I want 涉及金额、健康、法律、合同、身份或他人隐私时明确区分陈述、已确认事实和未知, so that 敏感内容不会被角色补全。
59. As a 玩家, I want 新增现实资料可以补充案件但不能抹掉讨论经过, so that 修正不等于改历史。
60. As a 玩家, I want 今天的评价不能替代当时真实做出的选择, so that 结案仍能区分当时和现在。

## Implementation Decisions

### 命令

法庭命令接口至少支持：

- 提交案件并判断是否适合开案。
- 回答开案补充问题。
- 确认或修正开庭前卷宗，包括本次可用资料范围。
- 进入某个阶段的首次全员庭审。
- 继续当前阶段，可选择点名角色。
- 补充、更正、否定路径、标记不确定、指出角色不符合经历。
- 确认当前阶段并进入下一阶段。
- 回退到上一阶段并触发全员重审。
- 确认回退阶段后回到离开时的阶段。
- 暂停离开与继续未完成阶段。
- 保存为审理中或待补充。
- 在已决定或无法验证时确认结案并签名。
- 按内容范围授权或撤回授权。
- 取消当前运行。

阶段不会因为角色发言次数或书记员判断而自动推进。结案不会因为三个阶段都讨论过而自动完成。

### 状态

案件可见状态至少包括：需要补充、审理中、待补充、已结案。

未完成现实选择的案件不得进入已结案。不得使用“尚未决定”作为结案状态。

阶段状态至少包括：未开始、进行中、玩家已确认。回退后，被回退阶段重新进入进行中，直到玩家再次确认。后续阶段若受影响，其旧总结降为讨论记录，不能直接作为最终结论。

### 材料分级

必须能区分并保存：

- 玩家确认的事实。
- 玩家叙述。
- 玩家当前评价。
- 玩家标记的不确定。
- 角色分析与未确认假设。
- 玩家确认可行的路径。
- 玩家明确否定的路径。

只有玩家确认的事实、路径、理由、前提、边界和评价可以进入结案档案。本域事件和 indexing 投影只能包含其中玩家当前仍授权的子集。

角色新路径的默认去向是讨论中的假设。玩家确认“当时真实可行”后，才能进入案件档案和决策资料事件。

### 运行

首次全员庭审、继续追问、回退全员重审、书记员总结都创建运行并流式输出。取消只丢弃这次未提交生成。已提交的发言、总结、玩家更正保留。

过去的你不得使用后来才知道的结果。审计员不得在无资料时补写现实信息。书记员不得宣布哪条路正确，也不得把未确认内容写成事实。

### 与 indexing

结案、授权变更或撤回后发布本模块领域事件。payload 使用决策资料字段，不要求消费者理解阶段或角色。未结案案件不发可检索的决策资料。未确认假设即使仍在庭审记录中，也不进入事件。撤回后 indexing 必须立即对后续查询不可见。

## Testing Decisions

主测试缝是法庭命令接口。测试用内存适配器，不连中间件。

必须覆盖：

- 信息不足时不能进入庭审。
- 阶段不自动推进；未确认进入下一阶段时仍停在当前阶段。
- 继续当前阶段时可以点名角色；未点名则只让相关角色继续，而不是默认五人全部重来。
- 角色提出的路径在玩家确认前不会出现在结案档案或决策资料事件中。
- 回退会基于最新确认内容触发全员重审；旧后续总结不能当作最终结论。
- 尚未决定的案件拒绝结案，只能保存。
- 结案档案能区分实际路径和未选择路径，且不含未确认假设正文。
- 撤回授权后，后续决策资料事件使 indexing 不再暴露对应字段。
- 取消当前生成后没有半段发言落库；已提交发言仍在。
- 模型即使输出后来才知道的结果，过去的你那次提交也会被拒绝。

不断言五个角色的提示词原文、表结构或检索实现。

## Out of Scope

- 无限增加新的阶段主题。
- 中途把案件改成另一个选择。
- 用分数评价选择或自动给出人生建议。
- 自动读取玩家未允许的资料。
- 把未结案案件转换成未来选择宇宙。
- Fork、通知、改写现实结果。

## Further Notes

法庭不判断哪条路更好。结案档案中“我现在如何理解这次选择”是玩家确认的当前评价，不是对错判决。
