# 平行宇宙档案馆 UI 风格

## 1. 视觉定位

以私人书房与平行宇宙档案馆为主体，用低调、克制的暗色科技细节表现“时间线被观测与持续构建”。

不是赛博朋克控制台，也不是复古奇幻图书馆。书架、书脊、档案页承担叙事入口；星图、时间刻度、微光和半透明层用于提示它们是独立平行宇宙。

### 1.1 气质关键词

- 沉浸式
- 档案馆
- 书架
- 平行宇宙
- 低调科技
- 阅读优先
- 暗色环境 + 浅色档案页

### 1.2 非目标

- 不做赛博朋克 HUD、霓虹灯、数据大屏。
- 不做厚重拟物、复古奇幻 RPG 质感。
- 不把书架做成普通卡片列表或数据看板。
- 不用颜色单独传达状态或语义。

## 2. 色彩系统

### 2.1 整体策略

- 外层环境与书架保持暗色，营造私人书房氛围。
- 打开宇宙后，主阅读区切换为暖白或浅灰纸张。
- 深色侧边时间线与浅色档案页形成“从书架抽出并翻开一本书”的仪式感。
- 页面切换必须克制，避免大面积闪白；通过短暂的淡入和纸页展开感连接两种表面。

### 2.2 建议色板

| 角色 | 建议值 | 用途 |
|------|--------|------|
| 环境背景 | 近黑深蓝灰 `#0F172A` 或 `#0B1220` | 书架、外层导航、暗色环境 |
| 书架材质 | 低饱和深胡桃木或炭黑木纹 | 书架页大面积出现 |
| 书封色 | 深靛蓝、墨绿、酒红、焦茶等低饱和色 | 区分不同宇宙 |
| 档案页背景 | 暖白 `#FAF8F2` 或浅灰 `#F4F2EC` | 事件阅读区、当前状态 |
| 正文文字 | 深石墨 `#1F2937` 或 `#334155` | 档案页正文 |
| 次要文字 | 中灰 `#64748B` | 时间、状态、辅助信息 |
| 强调色 | 冷金 `#D4A853` 或柔和琥珀 `#EAB308` | 当前宇宙、等待决策、关键节点 |
| 状态色 | 不只靠颜色，必须配合图标和文字 | 各状态标识 |

暗色环境下文字需满足 4.5:1 对比度；浅色档案页正文需满足 4.5:1 对比度。

### 2.3 深色模式

- 外层书架始终为暗色，不提供浅色书架模式。
- 档案页默认浅色；是否提供“深色纸张”模式可作为后续能力。
- 若未来支持深色纸张，阅读区仍保持与背景拉开的深灰/深蓝“纸页”表面，搭配偏暖文字。

## 3. 字体与排版

### 3.1 字体气质

- 标题使用现代、克制的无衬线字体，避免夸张科幻感。
- 正文使用高可读性的衬线或人文无衬线字体，强化档案与书籍感。
- 代码或编号可使用等宽字体，例如 `JetBrains Mono`，但仅用于编号和标签，不用于正文。

### 3.2 排版原则

- 档案页正文按书籍阅读习惯排版：行长 `60-75` 字符，行高 `1.5-1.75`。
- 事件标题层级清晰但不压倒正文。
- `我的行动`使用小标题和较深文字，位于正文末尾，以细分割线隔开。
- 时间信息使用较小字号和次要颜色，不抢夺正文层级。

### 3.3 建议层级

| 层级 | 示例 |
|------|------|
| 宇宙名称 | `017 号宇宙：加入创业团队之后` |
| 宇宙内时间 | `2027 年 5 月` |
| 事件标题 | `全职邀请` |
| 事件正文 | 事件发生的中性叙事 |
| 我的行动 | 最终采取的行动 |

## 4. 书架

### 4.1 书籍形态

- 每个宇宙以立体书脊或半露封面的形式出现，而不是普通卡片。
- 系统根据宇宙起点、主要事件和名称生成抽象封面。
- MVP 可先使用可配置的色块、星图、路径线和几何纹样。
- 不出现真实人脸或写实生活图。
- 后续可接入带 `skills` 的生图能力，为宇宙生成更具独特性的封面。

### 4.2 书脊信息

- 只显示 `*** 号宇宙`、名称和状态符号。
- 不显示宇宙内当前时间、最近事件标题或详细状态说明。

### 4.3 状态表达

- 使用色带、图标和简短文字表达状态。
- 例如琥珀色带配暂停图标与“等待决定”。
- 不同状态使用一致的状态词与图标，书架页面和宇宙详情页同步。
- 不能只依赖颜色传达状态。

## 5. 打开宇宙

### 5.1 过渡动效

- 采用“书脊抽出 → 封面展开 → 翻书 → 档案页落位”的连续过渡。
- 翻书是明确可见的动态画面，但总时长控制在约 `300-450ms`。
- 用户可随时打断动画。
- 降低动态效果开启时，退化为淡入与轻微位移，不保留翻页/纸张卷曲动画。

### 5.2 档案页

- 是具有明确边界的浅色纸页，悬浮在暗色环境中。
- 使用温和阴影、细边与适合长文的有限行宽。
- 不使用拟真的厚重纸纹、卷边或泛黄效果，保持现代档案感。

## 6. 阅读布局

### 6.1 桌面端

- 左侧为浅色、可滚动的事件时间线。
- 右侧主区域为悬浮在深色环境中的浅色档案页，展示当前选中事件。
- 时间线与档案页位置按需求交换，不是暗色时间线在左、浅色正文在右的布局。

### 6.2 移动端

- 默认只展示浅色档案阅读页。
- 事件时间线收进左侧抽屉，按宇宙内时间顺序浏览。

### 6.3 事件详情排版

事件详情按固定顺序排版：

```text
宇宙内时间或时间范围
事件标题
事件正文
我的行动（存在时）
```

- `我的行动`位于正文末尾，以细分割线分隔，采用小标题和较深文字。
- 不抢占事件叙事的层级。

## 7. 决策区

### 7.1 未完成重大事件

- 浅色档案页只呈现已经发生的情境和中性背景。
- 决策放在档案页底部之外、独立的深色操作区。
- 既保持阅读区是“已经发生的档案”，也明确提示时间线此处尚未落定。

### 7.2 第一层：是否介入

- 展示两张并列的控制权卡片：`我来介入` 与 `让平行的我决定`。
- 保持同等视觉重量，仅通过图标、标题和一句中性说明区分。
- 不做系统推荐，不以主次按钮暗示偏好。
- 点击“我来介入”后，切换为 `3-4` 张具体行动卡和“自定义方向”。
- 点击“让平行的我决定”后，系统先显示行动，不预告后果。
- 卡片可支持点击，桌面端也可探索轻量左右拖动，但不能只依赖手势。

### 7.3 第二层：行动卡组

玩家选择“我来介入”后，底部出现一叠行动卡。

- 屏幕中央只有一张大卡，显示当前行动的标题和简短说明。
- 左右两侧露出相邻选项约 `30-40%`，提示可继续浏览。
- 中心卡约占决策区宽度 `60%`。
- 通过拖动、点击左右露出部分、或使用左右箭头切换当前卡。
- 每次切换后点击“确认此行动”，才能最终落定。
- 自定义方向是卡组的最后一张卡，视觉上不弱化。
- 卡片不是事件本身，不进入时间线；行动确认后，只保留事件叙事和“我的行动”。

### 7.4 切换动效

- 旧卡向对应方向滑出，新卡反向滑入。
- 配合轻微缩放，增加卡组和方向感。
- 不做夸张 3D 翻页。
- 鼠标滚轮不用于切换卡片。

## 8. 当前状态

### 8.1 展示形式

- 事件详情主区域顶部默认显示一句“当前状态”摘要。
- 点击后以抽屉或浮层展开完整的当前状态事实。
- 当前状态不占用事件正文空间。
- 推演任务状态由宇宙列表、侧边栏当前节点的颜色/图标和操作按钮表达。

### 8.2 内容边界

- 只包含已经发生的事实、正在进行的计划或明确状态。
- 不包含风险判断、心理揣测和未来预测。

## 9. 动效原则

- 微交互时长保持在 `150-300ms`，复杂过渡不超过 `400ms`。
- 使用 `transform` 和 `opacity` 动画，避免影响布局的属性。
- 进入动画使用 ease-out，退出动画更短。
- 尊重 `prefers-reduced-motion`；开启减少动态效果时，所有翻页、滑入滑出、缩放动画降级为淡入淡出或即时切换。
- 动画必须表达空间连续性，不做纯装饰性动画。

## 10. 响应式原则

- 书架和阅读布局优先适配桌面端，移动端保持单栏阅读和抽屉时间线。
- 触控目标不小于 `44×44pt`。
- 档案页在移动端保持适合长文阅读的行长，不追求与桌面端完全一致的页宽。
- 侧边栏在移动端不固定展示，避免压缩正文空间。

## 11. 可访问性

- 所有图标按钮提供可访问标签。
- 颜色不作为唯一信息载体，状态、当前节点和决策结果必须配合图标或文字。
- 键盘可完成所有关键操作，包括切换卡片、确认行动和打开抽屉。
- 焦点状态清晰可见。
- 文字对比度满足 WCAG AA。
