# 个人偏见偏振器 Spec

玩法以 `02-bias-polarizer.md` 为准。跨游戏运行、授权、检索、取消和防腐以 `04-backend-spec.md` 为准。

## Problem Statement

玩家需要检视自己经常使用的一条判断：它在什么范围内成立、靠什么支撑、可能在哪里失效。如果一问一答就换题，或者反方自动进入结局，玩家会在还没说清时被定性。反方推测如果未经确认就进入档案馆，会被当成玩家的稳定判断。

玩家需要：最多五个主要质疑主题，主题内可以继续；下一步由自己决定；最终立场由自己确认；未确认推测不得外传。

## Solution

偏振器围绕一个玩家确认过的命题对打。一局最多五个主要质疑主题。每个主题可以多次追问，直到玩家接受当前整理或主动切换。反方可以建议下一个方向，但玩家决定继续、切换、指定方向或结束。

结局不是辩赢。玩家选择继续坚持、承认边界、修正判断、放弃命题或暂不确定，并确认适用范围、依据、保护的东西、失效条件和更新条件。只有玩家确认的内容可以按范围授权给档案馆。

生成过程走统一运行与 SSE；取消只停当前这次生成。

## User Stories

1. As a 玩家, I want 输入一句自己相信或正在动摇的命题, so that 对打有明确对象。
2. As a 玩家, I want 说明它更接近核心信念、情境判断还是尚不确定, so that 反方知道这不是人格标签。
3. As a 玩家, I want 命题不清时看到一个更明确的候选说法, so that 我可以确认后再开始。
4. As a 玩家, I want 系统不能把情绪描述擅自改写成人格结论, so that “我最近很累”不会变成“我不适合承担责任”。
5. As a 玩家, I want 人身攻击、歧视或伤害主张不能开台, so that 对打不处理这类内容。
6. As a 玩家, I want 含义过宽、无法说明范围或反例的命题先被拦住, so that 对打开始时我知道要检验什么。
7. As a 玩家, I want 一局最多五个主要质疑主题, so that 对打有边界。
8. As a 玩家, I want 一个主题不是一次问答, so that 没问清可以继续。
9. As a 玩家, I want 每个主题只处理一个主要问题, so that 我知道这次要回应什么。
10. As a 玩家, I want 反方尖锐但只攻击命题、证据和推理, so that 我不会被羞辱或被攻击身份。
11. As a 玩家, I want 反方不凭空添加我没有提供的事实, so that 质疑仍站在我给出的材料上。
12. As a 玩家, I want 至少一次文字回应或明确承认某前提未验证, so that 我不能只靠按钮打完一局。
13. As a 玩家, I want 选择定义、范围、证据、因果、反例、代价或更新中的一种质疑方向, so that 每次追问有明确角度。
14. As a 玩家, I want 如果我把讨论转到另一个命题，反方提醒一次并拉回, so that 当前问题不会被偷换。
15. As a 玩家, I want 再次转移时把当前问题记为未回答, so that 系统不继续纠缠，也不假装已经解决。
16. As a 玩家, I want 继续当前质疑时反方不得借机换主题, so that 继续就是继续。
17. As a 玩家, I want 要求反方澄清、纠正错误前提或补充说明范围, so that 我能挡住错误攻击。
18. As a 玩家, I want 点名希望反方从某个允许的角度继续, so that 我能主动检视代价或反例。
19. As a 玩家, I want 反方不得把未回答写成已经解决, so that 整理是诚实的。
20. As a 玩家, I want 没有新内容时得到提示，但仍可继续, so that 结束权在我。
21. As a 玩家, I want 反方建议下一个质疑方向, so that 我有可选择的下一步。
22. As a 玩家, I want 自己决定继续、接受建议、另选方向或进入结局, so that 反方不能自动换题或自动结束。
23. As a 玩家, I want 当前主题未经我确认充分时不因“已经提过五个主题”自动结局, so that 数量不是完成标准。
24. As a 玩家, I want 直接回应、提供经历、说明外部材料或他人观点, so that 我能解释这条判断从哪来。
25. As a 玩家, I want 缩小适用范围，或说明它只是当前判断不是原则, so that 我可以限缩而不必立刻放弃。
26. As a 玩家, I want 指出反方使用了错误事实, so that 后续质疑必须基于修正后的前提。
27. As a 玩家, I want 承认无法回答或不再相信这条命题, so that 我可以停在真实位置。
28. As a 玩家, I want 外部材料不被自动当成已验证事实, so that 依据来源仍然可区分。
29. As a 玩家, I want 完成五个主题、确认足以总结、认输、承认边界或主动结束时进入结局确认, so that 结束方式清楚。
30. As a 玩家, I want 认输只表示不再为当前表述辩护, so that 它不等于否定我整个人。
31. As a 玩家, I want 从继续坚持、承认边界、修正判断、放弃命题、暂不确定中选择最终立场, so that 结局是我的立场而不是胜负。
32. As a 玩家, I want 继续坚持仍带当前范围和依据, so that 它不会被写成普遍真理。
33. As a 玩家, I want 确认最终命题、适用场景、依据、保护的东西、失效条件和更新条件, so that 认知档案完整。
34. As a 玩家, I want 反方推测只有我明确同意后才能成为判断材料, so that 猜测不会变成我的信念。
35. As a 玩家, I want 认知档案区分确认判断、亲身经历、未验证依据、反方质疑和推测, so that 回看时不会混在一起。
36. As a 玩家, I want 一次对打不能被写成稳定人格, so that 偏振器不做人格测试。
37. As a 玩家, I want 按内容范围授权档案馆参考, so that 我可以只交出最终命题，留下私人经历。
38. As a 玩家, I want 随时撤回授权, so that 后续宇宙不再使用它。
39. As a 玩家, I want 反方质疑一段一段出现, so that 我能读完一段再决定是否继续。
40. As a 玩家, I want 取消当前这次生成, so that 半段质疑不会落库。
41. As a 玩家, I want 取消后仍停在当前主题, so that 取消不是结束对打。
42. As a 玩家, I want 涉及自伤、他伤、违法或极端危险时停止对打并提示寻求支持, so that 安全边界优先于游戏。
43. As a 档案馆, I want 只读到玩家确认且当前仍授权的判断材料, so that 未确认推测不会驱动平行的你。
44. As a 档案馆, I want 有边界的判断不被扩张成绝对性格, so that 宇宙里的人仍然先服从既定经历。
45. As a 实现者, I want 偏振器命令接口成为本游戏主测试缝, so that 主题继续、切换和结局规则可以不连中间件验收。
46. As a 实现者, I want 本域事件不携带反方未确认推测, so that indexing 天然带资料边界。
47. As a 实现者, I want 指出错误前提后后续生成必须使用修正前提, so that 反方不能继续攻击已经否定的事实。
48. As a 玩家, I want 刷新后只看到已提交的质疑和整理, so that 流式草稿不会冒充对打记录。
49. As a 玩家, I want 不把对打结果压缩成分数, so that 结局保持可阅读的立场而不是评分。
50. As a 玩家, I want 新的判断材料只影响既有宇宙当前节点之后, so that 过去的平行经历不被无痕改写。

## Implementation Decisions

### 命令

偏振器命令接口至少支持：

- 提交命题与当前状态，并判断能否开台。
- 确认或拒绝系统给出的更明确说法。
- 开始一个质疑主题。
- 文字回应、承认边界、承认证据不足、承认无法回答、放弃当前表述。
- 指出事实前提错误。
- 继续当前质疑，可指定允许的质疑角度。
- 接受当前整理并进入反方建议的下一主题，或自己选择另一允许方向。
- 结束对打并进入结局确认。
- 选择最终立场并确认认知档案字段。
- 按内容范围授权或撤回授权。
- 取消当前运行。

五个主题被提出过，不能单独作为进入结局的条件。玩家未确认当前主题充分时，不得自动结束。

### 状态

对打可见状态至少包括：需要澄清命题、对打中、已结局、因安全边界停止。

当前主题状态至少包括：进行中、玩家已接受整理。未接受整理时，下一主题不得开始。

必须保存：原始命题、玩家确认后的命题、当前质疑方向、已完成主题、未回答标记、玩家修正过的前提、最终立场。

### 材料分级

必须能区分：

- 玩家确认的判断。
- 玩家讲述的亲身经历。
- 玩家提供但未验证的依据。
- 反方质疑。
- 反方或系统推测。

本域事件和 indexing 投影只包含玩家确认且当前仍授权的判断、范围、依据、保护价值、失效条件和立场。未确认推测不出现。payload 使用画像资料字段。

玩家指出前提错误后，该错误前提不得再作为后续质疑的既定事实。后续运行必须带着修正后的前提。

### 运行

反方质疑、继续追问、主题整理、结局草案都创建运行并流式输出。取消只丢弃这次未提交生成。已提交的质疑、回应、整理保留。

反方不得把最坏情况写成必然，不得把一个反例夸大成命题必然错误，不得一次要求回答多个不同问题。

安全边界被触发时，立即停止对打，不生成后续质疑，不形成可授权的判断材料。

## Testing Decisions

主测试缝是偏振器命令接口。测试用内存适配器，不连中间件。

必须覆盖：

- 不合格命题不能开台；系统改写必须经玩家确认。
- 情绪描述不能被改写成人格结论。
- 当前主题未接受整理时不能进入下一主题。
- 继续当前质疑时不能更换主题。
- 玩家指定角度后，该次继续只围绕该角度。
- 指出错误前提后，后续提交不得再把该前提当事实。
- 未确认充分时，五个主题已出现也不能自动结局。
- 最终立场只能是玩家选择的那一种。
- 未确认推测不出现在认知档案的确认判断里，也不出现在画像资料事件中。
- 授权撤回后，后续事件使 indexing 立即不再暴露对应内容。
- 取消当前生成后没有半段质疑落库。
- 安全边界触发后不能继续对打。

不断言反方提示词原文、表结构或检索实现。

## Out of Scope

- 自动把浏览器收藏或外部文章导入对打。
- 自动验证玩家提供的外部材料。
- 用分数代表偏见或人格。
- 用一次对打生成稳定人格画像。
- 把反方推测自动写成玩家画像。
- Fork、通知、改写已经发生的宇宙经历。

## Further Notes

“继续坚持”只表示玩家在当前范围和依据下仍愿意保留该判断。结局或授权变更后发布本模块领域事件，供 indexing 异构为画像资料。档案馆只通过 indexing 使用这些资料，且宇宙既定经历和当前处境始终优先于抽象判断。
