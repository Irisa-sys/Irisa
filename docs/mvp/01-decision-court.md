# 前置游戏：人生决策法庭

## 1. 游戏定位

人生决策法庭帮助玩家重新审理一段真实的人生选择，把当时的处境、可行路径、实际决定和后续结果说清楚。

它不是咨询服务，不替玩家判断哪条路更好，也不预测另一条路一定会发生什么。它的作用是把一段真实经历整理成一份经过玩家确认的决策档案，供玩家回看，也可在玩家同意后作为平行宇宙档案馆的历史分叉起点。

法庭中的不同角色是帮助玩家思考的立场，不是现实中的裁判。角色提出的观点、假设和质疑，都不能替代玩家对亲身经历的确认。

## 2. 适合作为案件的选择

一个案件必须包含：

- 明确的选择时刻或时间范围。
- 当时确实存在的核心问题。
- 至少两条当时真实可行、但不能同时完全拥有的路径。
- 玩家能够区分现实中发生的事、自己的记忆、事后评价和推测。

适合的例子：

- 是否离开一份稳定工作。
- 是否搬到另一个城市。
- 是否接受一段关系或结束一段关系。
- 是否创业、转行或继续当前道路。
- 是否选择一个职业或发展方向而放弃另一个方向。

以下内容不足以直接成为案件：

- 只有“我最近状态不好”之类的模糊感受，没有具体选择。
- 只有现在的困扰，没有可以定位的过去时点或正在形成的选择。
- 事后设计出一条当时根本无法执行的路径。
- 无法区分已经发生的事实和现在对过去的评价。

## 3. 玩家需要回到当时看清什么

### 3.1 当时发生了什么

- 这件事为什么在当时变得重要。
- 当时有哪些背景变化。
- 为什么不能一直拖延。
- 当时已经知道什么，还不知道什么。

### 3.2 当时有哪些路

- 现实中实际走过的路是什么。
- 当时没有走的路是什么。
- 是否存在折中或第三条路。
- 每条路当时需要做什么。
- 每条路会得到什么、放弃什么。
- 哪些目标无法同时最大化。
- 哪些路只是事后想象，并非当时的真实选项。

### 3.3 当时处在什么位置

- 手里有什么资源：钱、时间、能力、机会和人际支持。
- 必须承担哪些责任。
- 有哪些现实限制。
- 哪些条件对自己有利。
- 哪些风险当时已经看见。
- 最坏可能发生什么。
- 哪些代价可以承受，哪些结果不能接受。

### 3.4 我真正看重什么

- 最想得到什么。
- 最害怕失去什么。
- 哪些东西不能牺牲。
- 愿意拿什么交换目标。
- 当稳定、自由、成长、收入、关系和意义冲突时，优先保住什么。

### 3.5 我为什么这样选择

- 支持这条路的理由。
- 反对这条路的理由。
- 最终真正起作用的判断。
- 当时默认会成立的前提。
- 当时没有确认、但影响了选择的猜测。
- 这个选择是主动争取，还是在现实压力下被迫接受。

### 3.6 后来现实发生了什么

- 已经发生了哪些结果。
- 结果是否符合当时的预期。
- 哪些意外事件改变了局面。
- 后来是否出现了新的选择。
- 玩家现在如何评价当时的决定。
- 哪些事情已经确定，哪些事情永远无法验证。

## 4. 法庭角色

| 角色 | 负责帮助玩家看清什么 |
| --- | --- |
| 过去的你 | 当时的初心、愿望、恐惧和自我理解 |
| 悲观主义者 | 最坏结果、脆弱环节和不可逆代价 |
| 机会主义者 | 被忽略的机会、替代路径和突破口 |
| 审计员 | 已知的现实约束、可确认的事实和资料空缺 |
| 书记员 | 各条路真正的差异、争议点和仍待确认的内容 |

### 4.1 过去的你

过去的你站在选择发生的那个时间点说话。它不能使用后来才知道的结果，不能用今天的价值观替代当时的想法，也不能把事后评价伪装成当时的动机。

### 4.2 悲观主义者

悲观主义者专门追问失败、损失、脆弱条件和最坏情况。它可以尖锐，但不能羞辱玩家，也不能把最坏情况说成必然结果。

### 4.3 机会主义者

机会主义者寻找当时可能被忽略的收益、窗口和第三条路。它可以鼓励冒险，但不能把机会描述成保证，也不能隐藏行动需要付出的代价。

### 4.4 审计员

审计员只陈述玩家已经提供或明确允许查看的事实。没有资料时必须明确说“卷宗空白”，不能凭空补充金额、健康、法律、合同或其他现实信息。

### 4.5 书记员

书记员不站队，不宣布哪条路正确。它负责区分：

- 已确认的现实事实。
- 玩家对经历的叙述。
- 玩家当前的评价。
- 尚未确认的假设。
- 各角色提出的分析。

## 5. 一局流程

### 5.1 开案

玩家先描述一个具体选择，包含：

- 案件标题。
- 选择发生的时间或时间范围。
- 当时面临的核心问题。
- 当时实际选择的路径；如果尚未决定，要明确说明。
- 玩家记得的候选路径，至少两条。
- 可选的财务、健康、关系、工作、地点和其他现实背景。

系统先检查这是否确实构成一个选择案件。如果信息不足，会提出最多三个最关键的补充问题。补充后仍无法定位选择时，案件停留在“需要补充”，不进入庭审。

### 5.2 开庭前确认

开庭前，玩家要确认一份简明卷宗：

- 选择发生在什么时候。
- 当时实际发生了什么。
- 当时有哪些真实可行的路径。
- 哪些内容是确定事实。
- 哪些内容只是记忆、评价或猜测。
- 本次庭审可以使用本次提供的哪些个人资料。

玩家可以在开庭前逐项修正卷宗。法庭角色不得擅自修改玩家确认过的事实。

### 5.3 三个庭审阶段

一局包含三个庭审阶段，每个阶段关注一个主题。阶段不是一次问答，也没有“每个角色发言一次就自动完成”的规则。玩家可以在当前阶段继续追问、补充和更正，直到确认已经说清楚，或确认接受仍然存在的不确定性：

| 阶段 | 主题 | 目标 |
| --- | --- | --- |
| 第一阶段：事实 | 当时发生了什么 | 还原时间、处境、资源和限制 |
| 第二阶段：路径 | 当时有哪些路 | 说明各条路要求什么、放弃什么 |
| 第三阶段：判断 | 为什么这样选 | 找出真正起作用的理由和前提 |

首次进入一个阶段时，五个角色依次参与：

1. 过去的你追问当时的初心和自我理解。
2. 悲观主义者指出脆弱环节和最坏代价。
3. 机会主义者寻找被忽略的机会和替代路径。
4. 审计员核对现实事实和资料空缺。
5. 书记员总结本阶段的共识、争议和待确认内容。

书记员总结后，玩家选择继续当前阶段，或接受当前整理并进入下一阶段。角色都发言过一次，或书记员认为材料已经足够，都不能自动推进阶段。

### 5.4 阶段内继续追问

如果玩家认为当前阶段没有达到想要的效果，可以选择“继续当前阶段”。继续时：

- 系统根据尚未解决的问题，邀请最相关的角色继续追问。
- 玩家可以点名一个角色继续追问。
- 相关角色应围绕当前阶段的主题和未解决的问题继续，不得无故开启新的主题。
- 玩家可以补充事实、更正内容、要求澄清，或指出角色误解了自己的经历。
- 书记员每次继续后都要重新整理已经明确的内容和仍然存在的空白。
- 如果连续追问没有产生新内容，书记员应明确提示“目前没有新的信息”，但玩家仍可以选择继续，或接受当前不确定性并进入下一阶段。

### 5.5 阶段推进与回退

玩家可以在当前阶段结束时选择进入下一阶段，也可以在完成后续阶段后回到上一阶段补充或更正。

回到上一阶段时：

- 以上一阶段截至当前的最新确认内容为基础。
- 重新进行一轮全员庭审对话，让五个角色都看到更新后的内容并重新回应。
- 全员庭审结束后，书记员重新总结该阶段。
- 玩家确认该阶段后，回到原先离开的阶段继续；如果修改影响了后续阶段，后续阶段的旧总结只能作为讨论记录，不能直接作为最终结论。
- 已经发生的庭审对话不删除，结案时以玩家最新确认的内容为准。

阶段回退不是抹除历史，也不是重新开始一局；它是基于最新内容重新审理被补充的阶段。

### 5.6 玩家在庭审中的回应

每个阶段的庭审对话结束后，玩家可以：

- 补充一条事实。
- 更正一条事实。
- 说明某条路径当时其实不可行。
- 补充当时没有说出的理由或限制。
- 把某项内容标记为“我不确定”。
- 说明某个角色的判断不符合自己的经历。
- 不补充，继续当前阶段或接受当前内容。

玩家的更正会保留原先说法作为讨论痕迹，但结案时以玩家最新确认的内容为准。角色提出的假设不会因为被重复提及就变成事实。

### 5.7 暂停和继续

- 玩家可以在任意阶段结束后离开，之后继续审理。
- 如果某个阶段尚未完成，玩家回来后从当前阶段未解决的问题继续。
- 已经确认的事实和玩家补充不会因为离开而消失。
- 一局只能围绕一个选择进行；想讨论另一个选择，需要另开案件。

## 6. 结案

### 6.1 结案前确认

三个阶段都完成后，玩家必须重新确认：

- 选择时点是否正确。
- 现实中实际走过的路径是什么。
- 当时可行但没有选择的路径是什么。
- 哪些内容是事实。
- 哪些内容是回忆、评价或未验证的假设。
- 平行宇宙档案馆可以使用这份案件材料中的哪些内容。

如果现实中的选择尚未完成，案件不能进入结案。它只能保存为“审理中”或“待补充”，等玩家完成现实选择后回来补充实际路径和结果。

玩家还要说明案件目前属于哪种状态：

- **已决定**：现实中已经做出并执行了选择。
- **无法验证**：现实中已经发生过选择，但关键事实或实际路径无法可靠还原。

只有现实中的选择已经完成，或玩家确认该选择已经发生但关键内容无法可靠还原时，玩家才能完成确认并签下卷宗，案件才算结案。签名表示玩家确认这份记录，不表示玩家同意任何角色的观点，也不表示某条路径更好。

### 6.2 结案档案

结案后形成一份玩家可以阅读的决策档案，至少包括：

- 案件标题和选择时点。
- 当时的核心问题。
- 现实中实际走过的路径。
- 当时没有走的路径和其他可行路径。
- 当时的资源、责任和现实限制。
- 玩家真正看重和害怕的东西。
- 最终起作用的理由。
- 玩家确认过的前提和边界。
- 后来现实发生的结果。
- 玩家现在对这次选择的看法。
- 哪些内容允许平行宇宙档案馆参考。

## 7. 资料边界

- 法庭角色不能创造玩家现实中没有提供的事实。
- 角色的分析、比喻和推测只用于帮助思考。
- 玩家没有确认的内容必须保持为假设或争议。
- 未经玩家确认的路径、事实或角色假设不能进入结案档案，也不能提供给平行宇宙档案馆。
- 现实中的结果不能被改写成另一种结果。
- 玩家今天的评价不能替代当时真实做出的选择。
- 新增的现实资料可以补充或修正案件，但不能抹掉原来的讨论经过。
- 未经玩家确认的路径、事实或角色假设不能进入结案档案；结案档案只能说明仍存在不确定性，不能把这些假设写成内容。

涉及金额、健康、法律、合同、身份或他人隐私时，法庭必须明确区分玩家陈述、已确认事实和未知内容。

## 8. 与平行宇宙档案馆的衔接

在玩家允许的前提下，档案馆可以使用：

- 选择发生的时间和起始处境。
- 现实中实际选择的路径。
- 当时未选择的路径和其他可行路径。
- 当时的资源、责任、限制和风险边界。
- 玩家看重和害怕的东西。
- 选择理由、默认前提和不确定内容。
- 后来已经发生的现实结果。
- 玩家对这次选择的当前评价。

档案馆使用这些材料时必须遵守：

- 现实中的实际路径是现实边界，不能被平行宇宙改写。
- 未选择的路径可以成为历史分叉的起点。
- 现实结果只用于说明分叉从何而来，不会自动变成平行宇宙的后续经历。
- 新案件只能影响既有宇宙从当前节点开始的后续发展。
- 未经玩家确认的角色分析、路径或假设不会进入档案馆，也不能决定平行的你如何行动。
- 玩家可以按内容范围授权档案馆使用案件材料，也可以随时撤回授权。
- 撤回授权只影响档案馆之后的使用，不改写已经发生的平行宇宙经历。

## 9. MVP 范围与验收

MVP 必须支持：

1. 玩家提交一个具体选择并判断它是否适合作为案件。
2. 玩家在开庭前确认时间、路径、事实和不确定内容。
3. 五个固定角色围绕三个主题阶段完成庭审，每个阶段允许继续追问。
4. 玩家可以补充、更正、保留疑问或指出某条路径不可行。
5. 玩家可以拒绝进入下一阶段，并要求相关角色或指定角色继续追问。
6. 玩家进入下一阶段后可以回到上一阶段，并基于最新内容重新进行一轮全员庭审。
7. 庭审角色始终区分事实、叙述、评价和推测。
8. 尚未完成现实选择的案件只能保存，不能结案。
9. 玩家在结案前确认现实路径、未选择路径和案件状态。
10. 玩家通过签名确认最终卷宗。
11. 生成一份可阅读、可回看的决策档案。
12. 玩家可以按内容范围选择是否允许平行宇宙档案馆使用这份材料，并可以随时撤回授权。

MVP 不要求：

- 追加无限轮次的庭审。
- 让玩家随时更换案件主题。
- 自动读取玩家没有明确允许使用的资料。
- 用分数评价玩家的选择。
- 自动替玩家给出人生建议。

验收标准：

- 玩家能说清楚案件从哪个现实时间点开始。
- 结案档案能明确区分实际路径和未选择路径。
- 任何角色的观点都不会在未经玩家确认时成为现实事实。
- 档案馆可以使用被允许的材料创建历史分叉，但不能据此改写现实经历。
