# 前置游戏：人生决策法庭

## 1. 在平行宇宙中的业务职责

人生决策法庭负责把一段“我曾经面临过的选择”整理成可以继续探索的分叉背景。

它不负责预测另一条路的未来，也不负责替平行宇宙做后续决定。它只帮助玩家说清楚：当时发生了什么、有哪些路、实际走了哪条，以及为什么。这些内容是平行时间线的分叉设定，不用于持续比较现实与平行宇宙哪一条更好。

完整玩法见[人生决策法庭](../games/01-decision-court.md)。本文件只定义它为平行宇宙提供的前置业务内容。

## 2. 适合作为分叉的案件

一个案件要成为历史分叉，必须有一个明确的选择时刻，以及至少两条当时真实可行、但不能同时完全拥有的路。

适合的例子：

- 是否离开一份稳定工作。
- 是否搬到另一个城市。
- 是否接受一段关系或结束一段关系。
- 是否创业、转行或继续当前道路。
- 是否选择一个技术方向而放弃另一个方向。

只有“我最近状态不好”或“我不知道该怎么办”，但没有具体选择和时间点的内容，不足以形成历史分叉。

## 3. 法庭需要让玩家说清楚什么

### 我当时遇到了什么

- 这件事为什么在当时变得重要。
- 当时发生了哪些背景事件。
- 为什么不能一直拖延。

### 当时有哪些路

- 实际走过的路是什么。
- 没有走的路是什么。
- 是否存在折中或第三条路。
- 每条路具体需要做什么。
- 每条路会放弃什么。
- 哪些目标无法同时最大化。

### 当时处在什么位置

- 手里有什么资源：钱、时间、能力、机会、人际支持。
- 必须承担哪些责任。
- 有哪些现实限制。
- 哪些条件对自己有利。
- 每条路最可能遇到的风险是什么。
- 最坏会发生什么。
- 能承受什么代价，不能接受什么结果。

### 我真正看重什么

- 最想得到什么。
- 最害怕失去什么。
- 哪些东西不能牺牲。
- 愿意拿什么交换目标。
- 当稳定、自由、成长、收入、关系和意义冲突时，优先保住什么。

### 我为什么这样选择

- 支持这条路的理由。
- 反对这条路的理由。
- 最终起作用的判断。
- 当时默认会成立的前提。
- 当时没有确认、但影响了选择的猜测。

### 后来现实发生了什么

- 已经发生的结果。
- 结果是否符合预期。
- 哪些意外事件改变了局面。
- 后来是否出现了新的选择。
- 玩家现在如何评价当时的决定。
- 哪些事情已经确定，哪些事情永远无法验证。

## 4. 庭审角色如何帮助形成前置材料

| 角色 | 帮助玩家看清什么 |
| --- | --- |
| 过去的你 | 当时的初心、愿望和过去类似的选择 |
| 悲观主义者 | 最坏结果、脆弱环节和不可逆代价 |
| 机会主义者 | 隐藏收益、机会窗口和可能的突破口 |
| 审计员 | 已经知道的现实约束与可验证事实 |
| 书记员 | 两条路真正的差异、争议点和未确认前提 |

Agent 的说法是帮助思考的材料，不等于玩家经历过的事实。只有玩家确认过的内容，才能作为分叉背景的可靠部分。

## 5. 结案时的分叉确认

法庭结案后，玩家需要额外确认：

- 这是一个已经发生过的选择，还是尚未发生的选择。
- 当时现实中实际走了哪条路。
- 当时没有走哪条路。
- 哪些内容是玩家亲自陈述的事实。
- 哪些内容只是法庭中的观点或推测。
- 是否允许平行宇宙探索这条未选择的路。

当前对这次决定的评价不能替代当时实际发生的选择。例如：“我现在认为当时应该辞职”不等于“我当时辞职了”。

## 6. 提供给档案馆的个人材料

法庭产出的重点不是一个答案，而是一段经过玩家确认的决策叙事：

```text
我在什么时刻遇到了什么问题
当时有哪些可行的路
我实际走了哪条路
我没有走哪条路
每条路会得到什么、失去什么
当时的资源、责任和限制是什么
我真正看重和害怕什么
我为什么做出这个选择
后来现实发生了什么
我现在如何看待它
```

这些材料支持档案馆回答“如果当时走另一条路”，也支持它在后续选择点理解玩家当时的处境。

## 7. 后续案件的作用

新的法庭案件不是对旧分叉的覆盖，而是新的个人材料。

它可以：

- 说明玩家后来现实中遇到了什么新选择。
- 补充或修正玩家对某类问题的理解。
- 让档案馆看到玩家的判断方式是否发生变化。
- 影响某个平行宇宙当前节点之后的事件和选项。

它不能：

- 改变旧案件的决策时刻。
- 把玩家当时的现实选择改成法庭今天的建议。
- 改写平行宇宙已经发生的玩家选择。

## 8. 与平行宇宙档案馆的数据契约

### 8.1 档案馆读取什么

- 案件的决策时刻与分叉时点。
- 当时实际选择的路径。
- 未选择的路径，以及当时可行的折中或第三路径。
- 当时的处境、资源、责任、限制、支持条件和风险边界。
- 玩家真正看重和害怕的东西。
- 选择理由、默认前提和未确认猜测。
- 后续现实中已经发生的实际结果。
- 玩家对当时决定的事后评价。

### 8.2 档案馆如何使用

- 分叉时点和实际选择路径作为历史分叉的现实资料边界，不可改写。
- 未选择的路径、第三路径和玩家自定义替代行动，作为平行宇宙的起点候选。
- 当时处境、资源、限制和看重的东西，作为事件生成的约束与背景。
- 后续现实中的实际结果只用于定义分叉来源，不会同步进入平行宇宙后续推演。
- 新的法庭案件只影响既有宇宙当前节点之后的发展，不会重写过去。

### 8.3 不提供的功能

- 不替平行宇宙预测未来。
- 不替玩家在平行宇宙中做决定。
- 不评价现实选择是否正确。
- 不把法庭建议写成已经发生的事实。
